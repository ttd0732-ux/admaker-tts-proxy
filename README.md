# 광고영상메이커 (무료 서버 버전)

광고 내용을 적으면 목소리와 화면, 배경음악이 합쳐진 광고 영상을 만들어
다운로드하는 웹 앱입니다. Vercel 무료로 운영합니다.

## 구성

- `index.html` — 앱 본체 (파일 하나로 동작)
  - 1단계: 광고 내용 (제목·본문)
  - 2단계: 목소리 고르기 (기기 목소리, 여성·남성·기타)
  - 3단계: 화면·배경음악 고르기
  - 4단계: 미리보기와 영상 다운로드
- `bgm/` — 목사님이 주신 저작권 없는 배경음악 10곡
  - 파일 이름은 반드시 `bgm1.mp3` … `bgm10.mp3` 으로 올려주세요.
  - 앱의 3단계에서 배경음악 1~10으로 고를 수 있습니다.
- `api/tts.py` — 영상 다운로드용 목소리 서버 (Vercel 함수)
  - 브라우저에서 Edge 음성 서버로 직접 연결이 막혀 있어, 이 서버가
    대신 음성을 받아 MP3로 돌려줍니다. 유료 서비스, API 키가 필요 없습니다.
  - `GET /api/tts?voice=...&text=...&rate=0`
  - 허용 목소리: 한국어 Edge 목소리 9종(선희·지민·서현·유진·순복·인준·현준·봉진·현수)
  - 한 번에 한 문장, 최대 1000자까지만 받습니다.
